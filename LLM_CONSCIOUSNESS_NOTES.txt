SUPPORT & TROUBLESHOOTING
=========================

If dialogue won't start:
  - Check .env has your API key
  - Verify key is correct with: python -c "import os; print(os.getenv('OPENAI_API_KEY'))"
  - Check OpenAI account has credits/API access

If responses are slow:
  - Normal during high API load
  - Check your network connection
  - Verify OpenAI API status

If you want to test LLM directly:
  python src/llm_consciousness.py

If you want to see how consciousness works:
  python src/consciousness_loop.py        (original system)
