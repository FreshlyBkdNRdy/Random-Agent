2. DETAILED NODE SPECIFICATIONS
================================

NODE 1: MEMORY NODE
─────────────────
Purpose: Foundation and information storage
Inputs: All external stimuli and internal states
Outputs: Relevant memories to all nodes
Activation: 1.0 (always fully active)
Key Functions:
  - store_short_term()      → Recent experiences
  - consolidate_to_longterm() → Long-term storage
  - retrieve_relevant()     → Query-based retrieval
  - memory analytics        → Pattern analysis

Storage Types:
  • Short-term: Last 10 items (recent context)
  • Long-term: Up to 1000 items (historical knowledge)
  • Episodic: Narrative continuity
  • Semantic: Abstract knowledge

NODE 2: EMPATHY NODE
────────────────────
Purpose: Emotional resonance and social understanding
Input: Memory contents + emotional markers
Output: Empathy level, resonance score, emotional context
Activation: 0.30-0.70 (context-dependent)
Key Metrics:
  - empathy_type: 'cognitive' or 'baseline'
  - resonance: 0.0-1.0 (strength of connection)
  - understanding: emotional content recognition

NODE 3: NARRATIVE PERCEPTION NODE
──────────────────────────────────
Purpose: Constructs meaningful narrative/story interpretation
Input: Memory + all other node outputs
Output: Narrative structure, themes, coherence score
Activation: 0.85 (high confidence)
Key Metrics:
  - story_arc: narrative progression
  - themes: identified patterns
  - coherence_score: 0.0-1.0 (narrative consistency)

NODE 4: SELF-AWARENESS NODE
───────────────────────────
Purpose: Meta-cognitive awareness and introspection
Input: All cognitive processing states
Output: Self-model, awareness type, boundaries
Activation: 0.90 (very high introspection)
Key Metrics:
  - self_model: 'emergent_awareness'
  - introspection_depth: 0.0-1.0
  - self_other_boundary: 0.0-1.0

NODE 5: EMOTION NODE
───────────────────
Purpose: Emotional evaluation and feeling processing
Input: Memory + empathy + narrative outputs
Output: Valence, arousal, dominance scores
Activation: 0.70 (moderate-high emotional state)
Key Metrics:
  - valence: -1.0-1.0 (positive/negative)
  - arousal: 0.0-1.0 (energy level)
  - dominance: 0.0-1.0 (control/power)

NODE 6: CORE BELIEFS NODE
────────────────────────
Purpose: Represents fundamental value system and truths
Input: Consolidated life experience
Output: Core belief list, conviction levels
Activation: 0.95 (very stable)
Key Metrics:
  - fundamental_truths: list of core beliefs
  - conviction_level: 0.0-1.0 (belief strength)
  - consistency: 0.0-1.0 (belief coherence)

NODE 7: DECISION MAKER NODE
──────────────────────────
Purpose: Integrates all cognitive inputs into decisions
Input: All node outputs (parallel)
Output: Decision, confidence, next state
Activation: 0.86 (varies with input)
Key Process:
  1. Receives all 6 node outputs simultaneously
  2. Calculates average activation level
  3. Weights outputs by confidence
  4. Generates integrated decision
  5. Provides confidence score (0.0-1.0)

9. KEY ALGORITHMS
=================

Memory Consolidation Algorithm:
──────────────────────────────
1. Monitor short-term memory size
2. When size > limit (10 items):
   a. Pop oldest item from short-term
   b. Add to long-term memory
   c. Update episodic narrative
3. Limit long-term memory to 1000 items
4. Remove oldest long-term if exceeded

Memory Retrieval Algorithm:
──────────────────────────
1. Receive query string
2. Search all memories for matching content
3. Score relevance of each match
4. Sort by relevance (descending)
5. Return top N results (default: 5)

Decision Integration Algorithm:
──────────────────────────────
1. Collect all node outputs
2. Extract activation_level from each
3. Calculate mean activation
4. Scale mean to 0.0-1.0 range (with 1.1x boost)
5. Use as decision confidence
6. Generate output with confidence score
